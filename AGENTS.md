# AGENTS.md

Lingo is a Go web app that generates Anki flashcards with OpenAI. Users enter words, Lingo creates cards
(translation, IPA, example, definition) and packs them into an `.apkg` file that Anki imports directly.
Production: https://lingo.lanbin.dev, behind Cloudflare.

## Commands

| Task | Command |
|---|---|
| Start DynamoDB Local + MinIO | `make up` |
| Run the app (http://localhost:8080) | `go run main.go` (`make run` also rebuilds CSS) |
| Unit tests | `make test` |
| Integration tests (needs `make up`) | `make test-integration` |
| Live OpenAI smoke test (costs money) | `OPENAIKEY=sk-... go test -tags live -v ./internal/cardgen/` |
| Lint | `make lint` (locally installed golangci-lint v2) |
| Vulnerability scan | `make vuln` |
| Regenerate mocks | `make mocks` (mockery v3, config in `.mockery.yml`) |
| Rebuild CSS after changing template classes | `make css` (needs Node; output `web/dist/styles.css` is committed) |

`config.yaml` sets `mockopenai: true`, so local runs need no OpenAI key. The mock echoes the requested word.

## Architecture

```
main.go -> internal/app (wiring)
  internal/handler     HTTP: net/http ServeMux, middleware, htmx pages + JSON API, errors as *HTTPError
  internal/service     business logic: Card (DB cache -> generate -> store), APKG (build + upload)
  internal/cardgen     OpenAI adapter (openai-go v3, structured outputs); prompt in prompt/system.md
  internal/repository  DynamoDB (cards cache, table lingo_cards), S3 (apkg files), collections (static)
  internal/model       domain types + request validation (APKGRequest.Normalize/Validate)
  internal/config      viper config: config.yaml or env vars (key path uppercased, "." -> "_")
  apkg/                Anki .apkg builder (SQLite v11 schema, modernc.org/sqlite, no cgo)
  web/                 embedded html/template pages + partials, static files, compiled Tailwind CSS
```

Routes: public `/`, `/card`, `/collection`, `/language` (HTML via htmx). Bearer-key-protected `/api/collections/{slug}/...`.

## Conventions

- Go 1.27.4+ (the `go` directive in go.mod is the single source of truth for CI). Use the standard library first:
  routing is `http.ServeMux` with method patterns (`"GET /api/collections/{collection}/cards/{word}"`,
  `r.PathValue`), and middleware is plain `func(http.Handler) http.Handler` composed with `chain` in `handler.go`.
  Note that `"GET /"` matches every path, so the index page is `"GET /{$}"`.

- Interfaces are declared by the consumer (`handler.CardService`, `service.CardRepository`, `cardgen.GPTClient`...).
  Mocks are generated by mockery into `<pkg>/mocks`. Never edit them by hand; add interfaces to `.mockery.yml`.
- Generated mocks pass variadic args as one slice: `EXPECT().GetAll(ctx, c, []string{"a", "b"})`.
- Handlers return `error`. Use the `Err*`/`BadRequest` values in `internal/handler/error.go` for user-facing
  errors. Anything else becomes a generic 500.
- Log with `logger.WithContext(ctx)` so the request ID is attached. Wrap errors with `%w`.
- Tests: testify, table-driven, `t.Parallel()`. Use `testing/synctest` to control time, not injected clocks.
  DynamoDB tests that need a real server use the `integration` build tag.
- Configure components with functional options (see `cardgen.WithModel`).
- Prompts live in embedded `*.md` files, never as prose in Go code. Switch to `*.md.tmpl` + `text/template`
  only once a prompt needs variables.

## Gotchas

- **Never change collection or model IDs** in `internal/repository/collection.go`. They are baked into decks
  users already imported. `TestCollection_PinnedIDs` guards them. Add a new collection with new IDs instead.
- Note GUIDs are `sha1(model name + first field)`. Anki uses them to update existing cards when users re-import.
- Generated cards are cached forever in DynamoDB, keyed by the lowercased word + collection ID. Changing the
  prompt or model affects only words that haven't been generated yet.
- `cardgen/schema.go` must match the json tags of `model.Card` (`TestCardSchemaMatchesModel`).
- Anki renders note fields as HTML, so LLM output is HTML-escaped in `service.APKG.buildAPKG`. Keep it that way.
- Templates and static files are embedded with `go:embed`, so restart the app after changing them.

## Security rules

- Never log secrets or raw headers. `config.Config` implements `slog.LogValuer` with redaction, and
  `RequestLogger` redacts `Authorization`/`Cookie`. Add new secret fields to `LogValue`.
- Every word may trigger a paid OpenAI call. Public endpoints must stay behind `limits.*` (max words, max word
  length, words per minute per client IP) and the 64 KiB body limit.
- The client IP comes from TCP `RemoteAddr` unless `limits.clientipheader` is set. Set it to `CF-Connecting-IP`
  in production only together with `limits.trustedproxies` (Cloudflare CIDRs), otherwise clients can spoof it.
- The API keys in `config.yaml`/`config.docker.yaml` are for local development only.
